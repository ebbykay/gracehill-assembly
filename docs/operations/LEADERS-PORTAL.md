# Leaders portal
Public footer links to the dedicated HTTPS backend login route. Hosted preview serves a clearly disabled sign-in interface until the identity provider and database are configured. The operational runtime uses the same presentation with POST /auth/login, existing OIDC PKCE and session validation. No public signup or password collection. The separately labelled demo is fictional. Activation requires an approved identity provider/client, restricted database credentials, migrations and authorised leader provisioning. Do not use real records before acceptance testing.
