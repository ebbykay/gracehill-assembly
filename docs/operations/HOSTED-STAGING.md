# Hosted staging
The initial Render Node service runs only hosted-preview-server.mjs, a dependency-free health-only entrypoint. It rejects operational environment variables and does not expose the administrative API, login or database. The separate static administration preview is publicly accessible and contains no records. This is not a production deployment. After CI and hosting validation, provision a restricted database login and compatible identity provider, design hosted TLS/database configuration, and deploy the authenticated application with release approval. Do not place secrets in GitHub.

## Database health integration
The staging entrypoint optionally accepts STAGING_DATABASE_URL, restricted to a Render internal hostname and a separately provisioned least-privilege login. It executes SELECT 1 only. Set the variable through Render secret configuration, never GitHub. Install API dependencies before deploying this version. Readiness deliberately remains 503. Internal host validation is not a substitute for network controls or verified TLS; this is temporary synthetic-data staging only. Database role provisioning and migrations require an authorised write-capable connection; the Render query connector is read-only. Production credentials and external identity variables remain blocked.
