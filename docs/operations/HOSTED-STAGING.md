# Hosted staging
The initial Render Node service runs only hosted-preview-server.mjs, a dependency-free health-only entrypoint. It rejects operational environment variables and does not expose the administrative API, login or database. The separate static administration preview is publicly accessible and contains no records. This is not a production deployment. After CI and hosting validation, provision a restricted database login and compatible identity provider, design hosted TLS/database configuration, and deploy the authenticated application with release approval. Do not place secrets in GitHub.
