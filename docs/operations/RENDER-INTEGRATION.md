# Render staging integration
Adopt the existing gracehill-api-staging service through a reviewed Render Blueprint plan. The existing database and static preview remain outside Blueprint management. Do not create duplicates. The plan installs API dependencies and uses the liveness endpoint; auto-deploy remains disabled. STAGING_DATABASE_URL is a manual secret and must reference a restricted database login, not the database owner. Do not expose the database externally or use real records. Apply only after inspecting the plan and approving any changes. The health-only entrypoint remains isolated. Migrations require a write-capable internal administrative session; the current connector cannot perform them. The free database expires 2026-12-28. Identity provider provisioning and operational deployment are separate gates.
