# Administrative runtime
Opt-in development integration: configure DATABASE_URL with a restricted local service login, OIDC_ISSUER, OIDC_AUDIENCE, OIDC_JWKS_URL, ADMIN_ORIGIN (exact HTTPS origin), OIDC_CLIENT_ID, OIDC_AUTHORISATION_ENDPOINT and OIDC_TOKEN_ENDPOINT. Register the exact callback ADMIN_ORIGIN/auth/callback with a compatible provider supporting public-client PKCE and RS256 ID tokens. Use a trusted HTTPS reverse proxy to loopback API; never expose the API directly. The new minimal protected workspace is distinct from the legacy design preview and contains no operational records. Sign-out revokes the local session; provider logout remains unconfigured. Real provider verification, per-request module permissions, authentication audit, cleanup, dependency lockfile, browser tests and production deployment remain gates. Readiness remains 503. Do not use real church records.
