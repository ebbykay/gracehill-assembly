# Pages deployment
Set Settings > Pages > Source to GitHub Actions. The workflow assembles only six public pages, shared styles/scripts and the approved logo into dist. GitHub Actions deployment is the supported source; do not switch to branch-root deployment. The public URL is https://ebbykay.github.io/gracehillassembly/. Missing gallery and hero imagery is not supplied by this build. Admin and original designs are not included in the artifact; repository visibility is independent.
