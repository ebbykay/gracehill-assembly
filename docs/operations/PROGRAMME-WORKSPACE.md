
# Programme workspace
Authenticated editors and publishers access /admin/programmes on the operational API origin. Editors create and edit drafts and submit for review; publishers review, return, publish and archive. Search filters the first 100 returned records. Date inputs are UTC (Accra). Server-side permissions and revision checks remain authoritative; all text is escaped. The static preview is unchanged. Browser interaction tests, pagination, public-site publication, live identity and database provisioning remain required. No live records until production approval.
