# Gracehill administration command centre
Design direction: calm editorial typography, navy navigation, restrained gold accents, white surfaces and soft gray canvas. Desktop uses a two-column command centre and four metric cards; mobile uses an accessible disclosure menu and responsive stacked content. Dashboard indicators derive only from the current fictional records, not fabricated growth rates. The service agenda, review queue and shortcuts lead to existing modules. Icons are inline SVG and the design has no external dependencies. Shared navigation and card styles apply across all eleven administrative modules. Existing operational interactions remain in place. The monogram is an interface mark, not a replacement for the official church logo. Production authentication and data are not represented by this demonstration. CI checks all eleven modules at 320, 768 and 1440 pixels and tests dashboard navigation.
