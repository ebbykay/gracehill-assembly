# Authenticated operations workspace
Protected /admin/operations exposes role-specific resource pages linked to real same-origin APIs, not the public sample UI. Includes bounded lists, creation, search, member revisions, attendance registration and editorial/finance/care transitions. UUID references are manual in this increment. No hosted identity provider or database connection has been activated. Do not enter real data until privacy, role design and infrastructure are approved. Actual browser end-to-end database integration, budget editing, reporting, and deployment remain outstanding. The public demo remains isolated.
