# Programme management
Initial private JSON API: GET/POST /api/admin/programmes, PATCH /api/admin/programmes/:id, POST /api/admin/programmes/:id/transition. Editors create and edit drafts and submit for review; publishers return review to draft, publish or archive. Roles are resolved from an active session at each request. Writes require exact trusted Origin, JSON and bounded fields. Revision checks prevent lost updates; successful changes and audit entries are transactional. Listing is capped at 100 records; pagination, user interface, public publication pipeline, denied-action audit and production security review remain outstanding. Published database rows do not automatically appear on GitHub Pages. No real records before deployment approval.
