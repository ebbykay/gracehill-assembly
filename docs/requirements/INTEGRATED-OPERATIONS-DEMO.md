# Integrated operations demonstration
Attendance roster selection uses fictional membership rows and replaces the selected sample service aggregate when saved. Reports derive live session totals from the same in-memory records. Finance compares a sample expense ceiling against all undated sample transactions, using integer minor currency units for the dedicated summary. It is not a dated ledger, accounting system or approved budget. Ministry, media, pastoral care and communications have status-filtered worklists; no real scheduling, publication or delivery occurs. Printed reports remain fictional. All changes reset on reload. Operational requirements include consent, attendance data model, transactional accounting, authorization, audit, retention and backend persistence. Browser acceptance tests are required before release.
