# Service planning demonstration
The Programme Management demonstration includes a month calendar, programme selection, a fictional Sunday template, editable start time, participant assignments, integer activity durations, sequence controls, total duration and browser printing. Plans are held in memory per programme row and reset on reload. The template is illustrative and not an approved Gracehill order of service. Printing is explicitly labelled demonstration. No data goes to a server. Operational persistence, template approval, recurrence, assignments against actual identities, overlap checks, individual activity editing, export to editable documents and access controls must be implemented separately. Browser tests cover template, addition, reordering, removal, calendar navigation and reset.
