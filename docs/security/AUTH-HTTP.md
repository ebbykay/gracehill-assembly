# Administrative HTTP boundary
Opt-in handler exposes POST /auth/login, GET /auth/callback, GET /auth/session and POST /auth/logout. Exact HTTPS Origin required for POST; callback consumes browser-bound state. Duplicate cookies and callback parameters rejected. A process-wide fixed-window limiter protects login and callback (20 requests/minute total); production requires edge/distributed limits to avoid shared denial of service. No callback queries are logged. Handler is injectable for tests but not enabled by server startup yet: provider configuration, HTTPS reverse proxy, private admin page at /admin/, per-request role resolution, authentication auditing and cleanup are outstanding. Do not deploy or use real records.
