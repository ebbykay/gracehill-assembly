# Callback service
The service coordinates atomic login attempt consumption, PKCE code exchange, RS256 ID token verification including nonce and authorised party, internal enabled identity mapping and session issuance. It uses a public-client token endpoint contract (client_id and PKCE, no client secret); provider compatibility must be confirmed. No HTTP routes are exposed yet. Before enabling browser login, validate configuration at startup, add same-origin CSRF protections, rate limits, session middleware, logout, cleanup, security headers and full browser tests. Provider token response is not persisted. No actual provider or production hosting configured.
