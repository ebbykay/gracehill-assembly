# Administrative session foundation
This increment supplies PKCE S256 generation, random state and nonce, expiry validation, opaque hashed session credentials, secure cookie serialization and database session creation/resolution/revocation. Sessions expire after 15 minutes and require an enabled identity. These primitives are not wired to browser endpoints. Before enabling login, implement single-use server-side login attempt storage, callback state consumption, provider code exchange, ID token nonce validation, CSRF protection for mutations, per-request role lookup, session rotation, logout and cleanup policy. No actual provider or browser session is configured. Do not use real records yet.
