# Login attempt infrastructure
The database stores state and browser binding hashes, a short-lived nonce and PKCE verifier. The latter two must be readable by the trusted runtime for callback exchange; restrict database access and delete expired attempts. Atomic DELETE RETURNING binds consumption to both state and browser cookie and prevents replay. The authorisation URL is built from server-controlled HTTPS configuration only. No HTTP login or callback routes are enabled in this increment. Before enabling them, implement code exchange, ID token signature/issuer/audience/nonce verification, session issuance, CSRF protection, logout, rate limits and scheduled cleanup. Do not log callback queries or credentials. Provider configuration and private hosting are outstanding.
