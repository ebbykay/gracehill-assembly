# Token verification
Provisional provider contract: HTTPS issuer and configured JWKS endpoint, RS256 signed JWT access tokens with typ at+jwt, exact issuer and audience, required subject, issue time and expiry, maximum age 15 minutes and five-second clock tolerance. Use jose rather than custom cryptography. Provider selection must verify compatibility with this profile. Never accept ID tokens or token-supplied roles. The runtime maps verified issuer and subject to enabled database identities. No provider has been provisioned. Browser login, PKCE, session/revocation policy, MFA, production TLS and dependency lockfile remain separate release gates.
