# Security

This repository contains a prototype, not a secure administrative service. Do not enter real credentials or sensitive records. Report vulnerabilities privately to the repository owner; do not put sensitive details in public issues.

Before production: implement server-side authentication and authorisation, session handling, validation, abuse controls, minimal data collection, retention rules, backup/restore testing and audit logs. Confirm asset permissions and third-party dependencies. Keep credentials in deployment secrets, never JavaScript or Git history.
